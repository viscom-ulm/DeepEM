Deep-EM Playground:

Bringing Deep Learning to
Electron Microscopy Labs

Hannah Kniesel1, Tristan Payer1, Poonam Poonam1, Tim Bergner2, Pedro Hermosilla3 Timo Ropinski1,
1Visual Computing Group, Ulm University
2Central Facility for Electron Microscopy, Ulm University
3Computer Vision Lab, TU Vienna
Paper

Deep-EM Playground is a user-friendly, interdisciplinary tool designed by deep learning (DL) experts to help electron microscopy (EM) labs leverage DL without requiring expertise in coding or AI. It simplifies model training, testing, and deployment, making DL accessible to researchers at any experience level, guiding them towards deeper understanding of AI.

Key Features

  • ✅ Easy Setup – Thanks to the use of Lightning AI, users can train models without configuring GPU environments.
  • ✅ Seamless Collaboration – Easily share model training procedures and model weights with colleagues.
  • ✅ Structured Use Cases – A clear structure of EM specific use cases provides an overview of possibilities to bring DL into EM labs.
  • ✅ Standardized Workflow – Standardizing the implementation of use cases provides a clear structure and simplifies the learning curve.

Workflow

Each use case implementation follows a standardized workflow, structured into:

  • 🔹 Development: Users train, fine-tune and evaluate models, gaining hands-on experience.
  • 🔹 Inference: Trained models can be used immediately, including models shared by colleagues.

Deep-EM Playground empowers EM researchers to harness DL effortlessly, fostering innovation and collaboration across labs. It provides an interface for DL experts to make their work available to EM researchers by contributing their work to the playground.

Use Cases

Use cases are structures into three distinct tasks:

  • 📌 Image-to-Value(s): Extracting key numerical data from images (e.g. quantification of virus particles).
  • 📌 Image-to-Image: Transforming one image into another (e.g. segmentation).
  • 📌 2D-to-3D: Reconstructing 3D structures from 2D images (e.g. tomographic reconstruction).

Each task is demonstrated through use cases. A use case is developed by DL experts and made available through our playground. Each use case is defined by its primary focus (like segmentation) and its exemplary application (like segmentation of cellular structures). With a plug-and-play approach, researchers can easily adapt the application of the use case within the primary focus area (like segmentation of mitochondria) simply by changing the data—no coding required.

Getting Started

Getting started is quick and easy! Follow these steps to explore our platform:

  • 🚀 Explore Use Cases: Browse available applications and find one that fits your needs.
  • 📂 Upload Your Data: Simply provide your own dataset to adapt an existing use case.
  • ⚙️ Run and Analyze: Apply deep learning models with no coding required and evaluate results effortlessly.
